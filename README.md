# Cheesy HP

<img width="1280" height="630" alt="изображение" src="https://github.com/user-attachments/assets/818b9f9d-98a5-456e-aa16-395dc2538abf" />

In the development of a private Minecraft server full of casual players who like to have KeepInventory on, we came up with a solution to make deaths more punishing without taking away all the pros of KeepInventory.

In every vanilla dungeon, players can now find a new item called "Twisted Spores" (1-2 pieces per chest). Nine of those allow you to craft a special item - "Twisted Heart Mushroom". When consumed, this special mushroom gives a player one extra heart. A player loses a heart upon death if their overall heart count was over 10. We implemented this solution to make it compatible with custom Origin types for the "Origins" mod.
